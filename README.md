## desafio-2-agentcore

Estrutura do projeto para avaliação e red-team de agentes com AgentCore.

```
desafio-2-agentcore/
│
├── agent/                  # Código do agente
├── dataset/                # Datasets de avaliação
├── deepeval/               # Testes e métricas com DeepEval
├── agentcore-evaluation/   # Avaliação via AWS AgentCore
├── red-team/               # Testes de red-team
├── results/                # Resultados das avaliações
├── report/                 # Relatórios finais
└── README.md
```
